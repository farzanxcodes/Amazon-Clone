# Amazon Clone 🛒

A responsive Amazon-inspired website built using HTML5 and CSS3. This project recreates the basic design and layout of an e-commerce website.

## 🚀 Features

- Responsive Navigation Bar
- Amazon-style Search Bar
- Hero Banner Section
- Product Categories
- Shop Section with Multiple Products
- Responsive Layout
- Clean and Simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
Amazon-Clone/
│
├── index.html
├── style.css
├── amazon_logo (1).png
├── amazon_hero1.jpg
└── Product Images
```

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/farzanxcodes/Amazon-Clone.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
